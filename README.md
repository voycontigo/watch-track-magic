# My Series

quiero una web app (que luego pueda instalar en mi android) que me sirva para hacer seguimiento de las series de televisión que estoy viendo y las que he finalizado.



necesito que puedas buscar en algún repositorio todas las series y yo añadir las que estoy viendo, las que he finalizado, y las que tengo a medias.



quiero poder marcar los capítulos vistos de cada serie por si quiero retomarla, saber dónde me he quedado.



también quiero que diariamente se actualice de manera que si de una serie que está marcada como vista, añaden nuevas temporadas o capítulos, vuelva a salirme en el apartado de series incompletas.



quiero una interfaz sencilla, con una miniatura de cada serie y clasificadas según: viendo, pendiente, finalizada
